# GymNote

**日本語** | [简体中文](README.zh-CN.md)

ブラウザだけで完結する、パーソナル筋トレ記録アプリ。HTML / CSS / JavaScript のみで構成された純フロントエンド SPA で、ビルド不要・サーバー不要。GitHub Pages にそのまま公開できます。データは既定でブラウザのローカルストレージに保存し、任意で GitHub Gist をプライベートなクラウド同期先として利用できます。

> GymNote は個人開発のプロジェクトです。いかなるジム・AI プロバイダー・その関連会社にも所属しておらず、これらを代表するものでもありません。

---

## 🧭 3行でわかる GymNote

- **記録**：種目カードをタップ → 前回の重量・回数・セット数が自動で入力済み。数秒で記録完了
- **可視化**：ヒートマップ、部位別の疲労回復度、ボリューム推移、PR（自己ベスト）を自動集計
- **AI コーチ**：Claude / Gemini / ChatGPT から選択。トレーニングメニューの生成と身体分析を、記録データに基づいて実行

## ✨ 主な機能

### 記録（ログ）

- **カード形式のログ入力**：種目カードが画面全体に並び、選択すると対応する入力欄が開きます。記録後も種目一覧に留まるため、連続入力がスムーズです
- **前回値の自動入力**：種目ごとに前回の重量・回数・セット数を自動で引き継ぎ。重量とセット数にはよく使う値のクイック選択タグ付き
- **複数重量セット**：同じ日の同じ種目で異なる重量を扱えます。「＋」で重量セットを追加し、それぞれにセット数・回数・セット外回数を記録（ピラミッドセットやドロップセットも 1 レコードで完結）。AI コーチのメニュー設計もこの構造に対応
- **セット外回数**：正規のセットとは別に、追い込みや追加で行った回数を任意で記録できます
- **有酸素のインターバルモード**：エアロバイクとトレッドミルで「変速」を選択すると、ウォームアップ → 複数のインターバル区間（速度と時間を個別指定）→ スプリント → 合計時間、という構成で記録できます（ウォームアップ／スプリントは 0 分も可）。トレッドミルは区間ごとに距離とカロリーを推定します
- **身体データ**：体重（小数第1位まで）、腕囲、腹囲、胸囲を記録。「推移」タブで最新値・前回比・履歴を確認でき、編集・削除も可能
- **後追い入力**：過去の日付を選んで記録できるため、付け忘れた日も後から補完できます
- **消費カロリー推定**：トレッドミルは ACSM の式に基づき、体重・速度・傾斜からリアルタイムに距離とカロリーを推定します

### 分析（ダッシュボード / 推移）

- **ダッシュボード**：直近 7 日間の運動頻度の折れ線グラフ、直近 30 日の筋トレ／有酸素の比率、直近 4 週間のトレーニングボリューム推移
- **履歴**：日付ごとにすべての記録を閲覧。種目での絞り込み、1 件単位の編集・削除に対応
- **カレンダー**：GitHub のコントリビューショングラフ風のヒートマップ（直近 1 年）。取り組みの濃淡が一目でわかります
- **疲労回復度**：部位ごとのトレーニング量と経過時間から、回復率をリアルタイムに推定（脚 約72h、胸・背 60h、肩・腕 48h、体幹 36h、有酸素 24h。複数回のトレーニングは疲労が加算されます）。AI の「身体分析」の結果はここに反映され、推定値を上書きしてコメントが添えられます
- **部位別の統計**：直近 30 日のトレーニング分布をドーナツグラフで表示。部位ごとに固定色を割り当て（色覚多様性への配慮とコントラスト比を検証済み）、中央に合計回数、凡例に回数と割合を表示します
- **PR（自己ベスト）**：筋トレ種目は最大重量（2 セット以上連続で達成した場合のみ記録対象とし、単発の記録による誤判定を回避）、トレッドミル／エアロバイクは最長時間を記録。更新時はお祝いの通知が表示されます
- **ライト / ダークテーマ**：右上のボタンで切り替え。設定はローカルに保存され、次回起動時に復元されます

### AI コーチ（任意）

既定は **Anthropic Claude**。設定画面から Google Gemini・ChatGPT にも切り替えられます。3 つのモードがあります。

- **チャット**：記録データを踏まえて自由に質問できます。マルチターンの文脈を保持するため、毎回要約し直すことなく会話を継続できます。頼んでいないのにメニューを提示することはありません
- **トレーニングメニュー**：目標や時間の制約を対話で伝えてカスタマイズするか、ワンタップで生成。構造化されたプランはホーム画面の「AI コーチのおすすめ」に反映され、各項目を「完了」（その日の記録を自動生成。筋トレは複数重量セットに対応し、重量は 5kg 単位に丸め）、「調整」（強度・セット数・セット外回数を変更してから完了）、「却下」から選べます。新しいメニューを生成すると、未処理の前回分は置き換えられます
- **身体分析**：部位ごとのトレーニング量の偏りと疲労回復状況を分析し、構造化された結果を「推移」タブの回復度モジュールに反映します。アプリ側のアルゴリズムによる推定値をアンカーとし、数値フォーマットを制約することで、同じデータからは安定して同じ出力が得られるよう設計しています
- AI の提案は内蔵の器具リストで制約されるため、設定にない器具を勧められることはありません
- **複数セッションの履歴**：新規会話の開始、過去の会話の閲覧・切り替え・削除に対応。会話はモードごとにラベル付けされ、切り替えると対応するモードに自動で戻ります
- API キーを使わず、トレーニングデータをプロンプトとして書き出し、任意の AI のウェブ版に貼り付けて使うこともできます

### 同期・バックアップ

- **GitHub Gist クラウド同期**：自分の GitHub アカウントを無料のプライベートストレージとして利用します。記録と AI のおすすめリストは全デバイスで自動的にマージ同期され、削除・完了・却下も正しく反映されます（トゥームストーン方式のため、別のデバイスによって削除済みデータが復活することはありません）。AI のチャット履歴はローカルのみに保存され、同期対象外です（Gist ファイルが会話履歴で肥大化するのを防ぐため）
- **バックアップと移行**：JSON バックアップのワンタップ書き出し／読み込み（API キーや GitHub トークンなどの機密情報は自動的に除外されます）

## 🚀 デプロイ

本プロジェクトは静的ページのみで構成されているため、GitHub Pages での公開を推奨します。

1. このリポジトリを Fork またはクローンします
2. リポジトリの Settings → Pages で公開ブランチ（例：`main`）を選択します
3. リポジトリ名を `gymnote` にすると、`https://<ユーザー名>.github.io/gymnote/` で利用できます

`index.html` をダブルクリックしてローカルのブラウザで開くだけでも動作します。

> コードを変更した場合は Pages に紐づけたブランチへ push してください。GitHub が自動的に再デプロイします（反映まで 1〜2 分）。

## ☁️ クラウド同期の設定（任意）

1. GitHub で [Personal Access Token を作成](https://github.com/settings/tokens)します。必要なスコープは `gist` のみです
2. アプリの「設定」画面でトークンを貼り付け、「今すぐ同期」をタップします
3. アプリがプライベート Gist をクラウドストレージとして自動作成し、Gist ID を紐づけます
4. 別のデバイスで同じトークンを入力すると、同期時に同じ Gist が自動的に検出・紐づけされます

## 🤖 AI コーチの設定（任意）

既定では **Anthropic Claude** に直接接続します（推論と構造化出力に強く、メニュー設計や回復分析に適しているため）。「設定」画面から Google Gemini・ChatGPT（OpenAI）にも切り替えられます。

- **Claude（既定・推奨）**：[Anthropic コンソール](https://console.anthropic.com/settings/keys) で API キー（`sk-ant-...`）を取得します。既定モデルは Claude Opus 4.8、Sonnet 5 / Haiku 4.5 も選択可能です
- **Gemini**：[Google AI Studio](https://aistudio.google.com/apikey) で API キー（`AIzaSy...`）を無料で取得できます。既定モデルは Gemini 3.7 Flash（2026-08 リリース。コーディングとエージェント能力が大幅に強化。2026-12-31 までは導入価格 100万トークンあたり $0.75 / $3.75、2027-01-01 以降は $1.50 / $7.50）。ほかに Gemini 3.1 Pro（プレビュー版・推論性能が最高）、Gemini 3.1 Flash-Lite（最も低コスト）を選べます。旧来の Gemini 2.5 Flash / 2.5 Pro は 2026-10-16 に提供終了となるため、選択肢から削除済みです
- **ChatGPT（OpenAI）**：[OpenAI Platform](https://platform.openai.com/api-keys) で API キー（`sk-proj-...`）を作成します。組織のデータ共有設定で「Share inputs and outputs with OpenAI」を有効化し、無料トークンプログラムへの参加を確認したうえで、API アカウントの残高をプラスに保つと、条件を満たした共有トラフィックには自動的に無料枠が適用され、日次プールを超えた分のみ通常料金となります。用途の目安は、GPT-5.6 Terra（250万トークン/日）が日常的なコーチング、GPT-5.6 Sol（25万トークン/日）が本格的なトレーニング振り返り、GPT-5.6 Luna（250万トークン/日）が軽量で高速な Q&A です。なお ChatGPT Plus / Pro のサブスクリプションと API の利用量は別会計です

「設定」画面でプロバイダーを選び、対応するキーを貼り付ければ、「AI コーチ」画面ですぐに対話を開始できます。3 社のキーはそれぞれ独立して保存されるため、プロバイダーを切り替えても上書きされません。

> セキュリティに関する注意：本アプリはブラウザから選択した AI プロバイダーの API を直接呼び出します（Claude の場合は `anthropic-dangerous-direct-browser-access` ヘッダーを付与）。API キーと Gist トークンは現在のブラウザ内にのみ保存され、書き出したバックアップファイルには含まれません。信頼できないデバイスやブラウザ拡張機能が動作する環境にキーを保存しないでください。

## 📝 データ形式

- **ローカル保存**：`gymnote_*` というキーでトレーニング記録・身体データ・設定・会話・おすすめを保存します。初回起動時に旧バージョンの `chocozap_*` キーを自動的に引き継ぐため、リネームによるデータ消失は起こりません
- **筋トレの記録**は複数重量セット構造 `details.groups: [{ weight, reps, sets, extraReps }]` を採用（旧バージョンのフラットな `weight / reps / sets` も読み取り互換あり）。有酸素のインターバル記録は `details.variableSpeed / warmup / segments / sprint / time`。身体データと設定内の AI キーはローカル保存のみで、Gist 同期の対象外です
- **クラウド側の Gist ファイル** `gymnote-data.json`：`{ "workouts": [...], "recommendations": [...], "deleted": {...} }`。アップグレード時は旧ファイル `chocozap_workouts.json` も読み込み、次回の同期で新しいファイル名に書き込みます
- 日付はすべて**ユーザーのローカルタイムゾーン**で `YYYY-MM-DD` として記録されます

## 🌐 多言語対応

アプリの UI は**日本語と簡体字中国語**に対応しています。

- **言語の判定**：初回起動時はブラウザの言語設定を見て、中国語環境なら中国語、それ以外はすべて日本語で表示します
- **切り替え**：画面右上の「中／日」ボタンでいつでも切り替えられます。選択はブラウザに保存され、次回以降も維持されます
- **AI コーチも追従**：プロンプト自体が選択中の言語で組み立てられるため、AI の回答も日本語で返ってきます
- **記録データは言語に依存しません**：内部的には言語に依存しない形式で保存しているため、言語を切り替えても過去の記録・クラウド同期・バックアップはそのまま使えます

実装は `i18n.js` に集約しています（辞書、`t()` による取得、`data-i18n` 属性による静的ノードの差し替え、言語切り替え時の再描画）。新しい言語を追加する場合は、`I18N_DICT` に辞書を1つ足すだけで対応できます。
